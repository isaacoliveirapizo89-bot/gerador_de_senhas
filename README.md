# 🔐 Gerador de Senhas

Aplicação simples desenvolvida em **Python** para gerar senhas aleatórias de acordo com as opções escolhidas pelo usuário.

O projeto foi criado para praticar lógica de programação, entrada de dados e uso de recursos da linguagem.

## ✨ Funcionalidades

O programa permite:

- Definir o tamanho da senha.
- Escolher se deseja incluir letras maiúsculas.
- Escolher se deseja incluir letras minúsculas.
- Incluir números.
- Incluir símbolos.

## 🛠️ Tecnologia utilizada

- **Python**

## ▶️ Como executar

1. Instale o Python.
2. Clone o repositório:
   ```bash
   git clone https://github.com/isaacoliveirapizo89-bot/gerador_de_senhas.git
   ```
3. Acesse a pasta:
   ```bash
   cd gerador_de_senhas
   ```
4. Execute o programa:
   ```bash
   python gerador_de_senhas.py
   ```

## 💻 Exemplo de interação

```text
Digite o tamanho da senha: 12
Incluir letras maiúsculas? (S/N): S
Incluir letras minúsculas? (S/N): S
Incluir números? (S/N): S
Incluir símbolos? (S/N): S
```
