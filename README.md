# Gerador de Senhas

Este projeto é um simples gerador de senhas em Python.

## Como executar

1. Abra o terminal.
2. Entre na pasta do projeto:
   ```bash
   cd gerador_de_senhas
   ```
3. Execute o script:
   ```bash
   python gerador_de_senhas.py
   ```

## O que o programa faz

- Pergunta o tamanho da senha
- Permite incluir letras maiúsculas, minúsculas, números e símbolos
- Gera uma senha forte e aleatória

## Exemplo de uso

```text
Digite o tamanho da senha: 12
Incluir letras maiúsculas? (S/N): S
Incluir letras minúsculas? (S/N): S
Incluir números? (S/N): S
Incluir símbolos? (S/N): S
```
